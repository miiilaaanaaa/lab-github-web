# Игра в слова

## Описание
Консольная программа для игры в "Слова" между человеком и компьютером. Игроки по очереди вписывают слова на выбранную тему, где каждое слово начинается на последнюю букву предыдушего.

## Правила
1. В начале игры компьютер предлагает 3 темы: города, животные и растения.
2. Первое слово называет игрок.
3. Каждое слово должно:
   - начинаться на последнюю букву предыдущего;
   - соответствовать выбранной теме;
   - не повторяться.
4. Проигрыш наступает, если игрок:
   - не может назвать слово;
   - называет не по теме;
   - повторяет уже использованное слово;
   - называет слово не с той буквы.
5. Если слово заканчивается на "ь", "ъ" или "ы", используется предпоследняя буква.

## Возможности

- Объяснение правил при запуске.
- Уточнение правил в любой момент.
- Выбор темы из предложенных.
- Игра против компьтера.
- Проверка корректности ходов.
- Выход.
