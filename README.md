# Успеваемость

Система учёта успеваемости студентов.

## О проекте

Данный проект представляет собой информационную систему, предназначенную для автоматизации процесса учёта успеваемости студентов высших учебных заведений. Система позволяет преподавателям и сотрудникам деканата вести учёт оценок, формировать ведомости и получать аналитическую информацию об успеваемости отдельных студентов, групп и факультетов в целом.

Актуальность проекта обусловлена необходимостью снижения трудозатрат на обработку большого объёма данных об успеваемости и повышения точности формируемой отчётности.

## Цель проекта

Автоматизировать учёт оценок и формирование отчётов.

## Задачи проекта

- Обеспечить хранение информации о студентах, дисциплинах и оценках.
- Реализовать формирование ведомостей по дисциплинам и группам.
- Предоставить инструменты анализа успеваемости.
- Обеспечить разграничение прав доступа для разных категорий пользователей.

## Технологии

- Python
- PostgreSQL

## Запуск

Для запуска проекта требуется Python 3.10 и PostgreSQL.
