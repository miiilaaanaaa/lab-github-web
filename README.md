# Успеваемость

**Система учёта успеваемости студентов** — веб-приложение, которое помогает
преподавателям вести журнал, считать средний балл и строить отчёты без
бумажной волокиты и бесконечных Excel-таблиц.

## Цель

Автоматизировать учёт оценок и дать наглядную аналитику успеваемости,
избавив преподавателей от бумажных журналов и Excel-таблиц.

## Назначение

Веб-приложение предназначено для ведения электронного журнала, расчёта
среднего балла и построения отчётов по группам и предметам.

Его основная аудитория — преподаватели и кураторы групп, которым важно
быстро получать картину успеваемости. В перспективе система может быть
полезна и студентам — для просмотра своих оценок и статистики.

## Возможности

- [ ] Ввод и хранение оценок студентов
- [ ] Расчёт среднего балла
- [ ] Вывод списка студентов и их оценок
- [ ] Поиск студента по имени
- [ ] Формирование отчётов по группам
- [ ] Формирование отчётов по предметам
- [ ] Просмотр истории оценок студента
- [ ] Экспорт данных 
- [ ] Разграничение прав доступа

Пункты со временем будут отмечаться как выполненные — так удобно видеть,
на каком этапе находится проект.
