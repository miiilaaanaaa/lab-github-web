# Успеваемость

Система учёта успеваемости студентов.

## Цель

Автоматизировать учёт оценок и дать наглядную аналитику успеваемости,
избавив преподавателей от бумажных журналов и Excel-таблиц.

## Назначение

Веб-приложение для ведения электронного журнала, расчёта среднего балла
и построения отчётов по группам и предметам.
