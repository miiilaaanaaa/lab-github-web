> **Успеваемость** — информационная система для учёта, анализа и
> визуализации академической успеваемости студентов.

---

## 📖 О проекте

Проект представляет собой веб-приложение, позволяющее:

- вести учёт оценок студентов по дисциплинам;
- формировать ведомости и отчёты;
- анализировать успеваемость по группам и факультетам;
- выявлять студентов с академической задолженностью.

### 🎯 Цель проекта

Автоматизировать процесс учёта успеваемости, снизить трудозатраты
преподавателей и повысить прозрачность академических результатов.

### ❓ Зачем это нужно

| Проблема | Решение |
|---|---|
| Ручное заполнение ведомостей | Автоматический расчёт |
| Сложность анализа | Отчёты и графики |
| Потеря данных | Централизованная БД |
