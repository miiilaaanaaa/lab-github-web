# Руководство пользователя

## Вход в систему

1. Откройте браузер
2. Перейдите по адресу приложения
3. Введите логин и пароль
4. Нажмите **Войти**

## Добавление оценки

1. Выберите группу
2. Выберите дисциплину
3. Выберите студента
4. Поставьте оценку (2–5)
5. Нажмите **Сохранить**

## Формирование отчёта

1. Перейдите в раздел **Отчёты**
2. Выберите период
3. Нажмите **Сформировать**
4. Скачайте файл Excel
