# Требования к системе «Успеваемость»

## Функциональные требования

- Преподаватель добавляет и редактирует оценки
- Студент видит только свои оценки и средний балл
- Система считает средний балл по предмету и по семестру
- Система формирует отчёт по группе за период
- Разграничение доступа по ролям: преподаватель, студент, администратор

## Нефункциональные требования

- Интерфейс на русском языке
- Отклик интерфейса не более 2 секунд
- Работает в Chrome, Яндекс.Браузер, Firefox, Edge
- Пароли хранятся в хешированном виде

## Роли пользователей

| Роль | Права |
|---|---|
| Преподаватель | выставление оценок, отчёты |
| Студент | просмотр своих оценок |
| Администратор | управление пользователями и предметами |
